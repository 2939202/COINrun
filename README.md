# 코인런 (CoinRun)

달린 만큼 캐릭터가 강해지는 러닝 RPG 앱입니다.
GPS와 걸음 센서로 달린 거리와 걸음을 재고, 그만큼 **골드**와 **경험치**를 받습니다.
골드로 옷·배경·간식을 사서 3D 캐릭터를 꾸미고, 다른 러너와 대결하고, 친구와 길드에 모입니다.
AI 비서(Gemini)는 쌓인 기록을 보고 주간·월간 흐름을 분석해 줍니다.

- 플랫폼: Android (Flutter)
- 서버: Firebase (Authentication, Firestore, AI Logic, Hosting)
- 지도: OpenStreetMap (`flutter_map`)
- 3D: three.js(r160)를 WebView 안에서 실행

---

## 시연용 기능이 존재합니다!!

- **골드·레벨 지급**: 홈의 우측 상단의 골드를 빠르게 6번 연타하시면 레벨 10, 골드 30,000이 됩니다.
- **러닝 시뮬레이터**: 러닝 화면 나침반을 빠르게 6번 연타로 누르면 방향 버튼을 통해 밖에 나가지 않고 러닝을 시험할 수 있습니다. 다시 6번 누르면 꺼집니다!!

시연을 위해 출시 빌드에서도 열려 있습니다.

## 1. 한눈에 보는 흐름

```
로그인(익명 / 이메일)
  └ 홈
     ├ 러닝 ──────── 달리기 → 골드·경험치 → 기록 저장
     ├ 내 캐릭터 ──── 사람/개 고르기, 옷 입기, 간식 먹이기, 배경 바꾸기, 상점, 나의 길드
     ├ 게임 플레잉 ── 같은 등급 자동 매칭 → 3D 대결
     ├ 랭킹 ──────── 레벨·거리 순위
     ├ AI 평가 ────── 주간·월간 분석
     └ 플레이어 카드 ─ 내 캐릭터·랭킹·기록 카드, QR, 공유
```

## 2. 러닝과 보상

| 항목 | 기준 |
|---|---|
| 경험치 | 실제로 움직인 시간 1분당 10 EXP. 빠를수록 최대 30% 더 (5분/km 이상) |
| 골드 | 10걸음당 1골드 |
| 코스 러닝 골드 | 걸음 골드 대신 코스 위 코인 30개 × 20골드. 다 먹으면 편도 1.25배, 왕복 1.5배 |
| 장비 보너스 | 옷의 힘만큼 골드 +%, 체력만큼 경험치 +% |

- **움직인 시간**은 걷는 속도(1.0m/s) 이상으로 움직인 시간만 셉니다. 시작만 누르고 서 있으면 쌓이지 않습니다.
- **골드를 걸음으로 주는 이유**: 차를 타고 골드를 벌 수 없게 하기 위해서입니다.
- **부정 방지**: 시속 25km(7m/s)보다 빠른 구간은 거리·시간·코인에서 모두 뺍니다.
- **띠링 소리**: 골드가 오를 때마다 오른 만큼 "띠링"이 울립니다 (한 번에 최대 8번).
- 러닝을 마치면 거리와 페이스로 1~5 등급을 매깁니다. (`lib/game/run_grade.dart`)
- 전체 기록은 월별로 나뉘어 보이고, 지운 기록은 휴지통에서 되살릴 수 있습니다.

규칙 코드: `lib/game/run_rules.dart`, `lib/game/run_tracker.dart`

## 3. 코스 러닝

러닝 화면 오른쪽 위 버튼으로 일반 러닝과 코스 러닝을 오갑니다.

- 지금 위치의 구를 찾아(서울 25개 구 경계, `assets/geo/`) 그 구의 코스를 보여줍니다.
- **클래식 코스**: 앱 안에 들어 있습니다. (`lib/game/official_courses.dart`)
- **사설 코스**: 사용자가 직접 만들고, 다른 사람이 하트를 누릅니다. (Firestore `courses`)
- 코스를 만든 사람은 받은 하트로 **명예 레벨**이 오릅니다. (Lv.1 코스 1개 · Lv.2 하트 5 · Lv.3 15 · Lv.4 40 · Lv.5 100)
- 코스 위에 코인 30개가 깔리고, 지도를 멀리 축소하면 코인이 점으로 보입니다.
- 나침반은 양피지와 잉크 느낌으로 그렸습니다.

지도 타일은 OpenStreetMap입니다. 출처는 설정 > 지도 및 데이터 출처에 있습니다.

## 4. 캐릭터: 사람과 개

내 캐릭터 화면에서 **여자 · 남자 · 허스키 · 리트리버** 중 하나를 고릅니다.

### 사람
- 3D 모델 하나(`assets/models/character.glb`)에 남녀 머리·몸·옷이 겹쳐 있고, 입은 세트의 파츠만 켭니다.
- Mixamo 뼈대로 리깅했고 동작 6개가 들어 있습니다: 서 있기, 싸움 자세, 펀치, 맞기, 달리기, 걷기.

| 세트 | 이름 | 가격 | 3D 파츠 |
|---|---|---|---|
| basic | 기본 옷 | 무료 | basic |
| novice | 천옷 | 500 | fabric |
| adept | 가죽옷 | 3,000 | leather |
| master | 갑옷 | 12,000 | armor |

### 개
개는 펫이 아니라 **캐릭터**입니다. 간식을 먹을수록 3단계로 자랍니다. 단계마다 그림체가 바뀝니다.

| 단계 | 필요한 간식 | 모습 |
|---|---|---|
| 1단계 | 0개 | 흑백, 아주 굵은 픽셀 |
| 2단계 | 4개 | 흑백, 중간 픽셀 |
| 3단계 | 12개 | 은은한 색, 고운 픽셀 |

- 개는 이름을 지어 줄 수 있습니다. (이름표의 연필 버튼)
- 개는 숨쉬기만 합니다. 홈 카드에는 얼굴만 보입니다.
- 같은 단계 그림체가 3D, 홈 카드, 랭킹 등 모든 곳에 똑같이 적용됩니다. (`lib/widgets/look_image.dart`)

코드: `lib/game/character_outfit.dart`, `lib/game/pet_catalog.dart`

## 5. 인벤토리와 상태창

- **상태창**(오른쪽 위): 힘(골드 +%), 체력(경험치 +%), 속도, 명예. "더보기"를 누르면 각 능력치가 무엇을 올려주는지 나옵니다.
- **옷**: 보이는 옷과 능력치 옷을 따로 입습니다. (`outfitSetId`, `equippedSetId`)
- **간식**: 가진 간식 개수와 [먹이기] 버튼. 개를 고른 상태에서만 먹일 수 있습니다.
- **배경**: 캐릭터 뒤 배경을 고릅니다.

| 배경 | 가격 |
|---|---|
| 흰색 | 기본 |
| 검은색 | 기본 |
| 안개 들판 | 1,500 |
| 숲길 | 2,000 |

- 배경 2종

## 7. 게임 플레잉(대결)

- **자동 매칭**: 같은 등급의 러너를 찾습니다. 없으면 아래 등급에서 찾습니다. ("찾는 중" 화면)
- 두 캐릭터가 3D로 마주 서서 번갈아 공격합니다. 펀치·맞기·빗나감 소리가 나고, 맞으면 잠깐 빨개집니다.
- 능력치는 **레벨과 누적 거리로만** 정합니다. 많이 달린 사람이 강합니다.

```
체력 = 100 + 레벨×12 + 누적km×0.5 (거리 몫은 최대 150)
공격 = 10 + 레벨×2 + √누적km×1.5
방어 = 4 + 레벨
속도 = 레벨 + √누적km   → 높은 쪽이 먼저 칩니다
```

- 같은 상대와는 하루 동안 결과가 같습니다(두 사람과 날짜로 난수 씨앗을 정함). 이길 때까지 다시 하기를 막습니다.
- 연습 대결이라 보상은 없습니다. 보상을 붙이려면 조작 방지를 위해 서버에서 계산해야 합니다.

코드: `lib/game/pvp_battle.dart`, `lib/screens/pvp_screen.dart`

## 9. 플레이어 카드와 친구 링크

홈의 레벨 카드를 누르면 전체 화면 플레이어 카드가 열립니다.

- 큰 고화질 캐릭터, 닉네임, 플레이어 번호, 등급과 순위, 총 거리·러닝 횟수 등 기록, 가입일
- **QR 코드**와 **공유 버튼** (카드를 그림으로 만들어 공유)

**친구 링크**: `https://spot7123-3ad2d.web.app/p/<uid>`
1. 휴대폰 기본 카메라로 QR을 찍거나, 카톡 등으로 받은 링크를 누릅니다.
2. 초대 페이지(`hosting/p/index.html`)가 `coinrun://app/player/<uid>`로 코인런 앱을 엽니다.
3. 앱이 "○○님에게 친구 요청을 보낼까요?"라고 묻습니다.

카톡은 `coinrun://` 링크를 눌리는 링크로 만들어 주지 않아서 https 페이지를 거칩니다.

코드: `lib/screens/player_card_screen.dart`, `lib/services/link_service.dart`, `lib/widgets/friend_link_handler.dart`, `MainActivity.kt`

## 10. 나의 길드

내 캐릭터 화면의 **나의 길드**로 들어갑니다.

- 원근감 있는 실내 배경. 조이스틱으로 내 캐릭터를 움직이고, 친구들은 스스로 걸어 다닙니다.
- 벽 액자에 길드장(나)의 초상화가 걸려 있습니다.
- **친구 추가**: 플레이어 번호로 찾기, 또는 내 친구 링크 공유
- **알림**: 받은 친구 요청은 길드 화면의 친구 버튼에 숫자로 표시되고, 거기서 수락합니다. (푸시 알림은 없습니다)
- 상대가 이미 나에게 신청했다면 내가 신청하는 순간 바로 친구가 됩니다.

코드: `lib/screens/guild_screen.dart`, `lib/services/friend_repository.dart`

## 11. AI 평가

숫자는 폰에서 계산하고, 문장만 Gemini가 씁니다. AI가 숫자를 지어내지 못하게 검사합니다.

| 맡는 것 | 파일 |
|---|---|
| 점수(꾸준함·운동량·흐름), 기본 분석 문장 | `lib/game/run_insights.dart` |
| 역치 페이스, 러닝 부하, 체력·피로, 급성:만성 부하비 | `lib/game/training_model.dart` |
| 러닝 한 번의 부하도(1~5), 체감 보정 | `lib/game/run_load.dart`, `lib/game/felt_calibration.dart` |
| 이번 주 목표 (화면에서는 빼 둠) | `lib/game/goal_policy.dart`, `lib/game/week_plan.dart`, `lib/services/week_coach.dart` |
| 월간 달력 | `lib/game/run_calendar.dart` |
| Gemini 호출, 말투 검사, 저장 | `lib/services/ai_coach.dart` |
| AI 문장 속 숫자가 실제 기록에서 나왔는지 검사 | `lib/services/ai_guard.dart` |

- 화면: AI 비서 프로필, 한 줄 평, [더보기]로 펼치는 조언 목록, 답장하기
- Gemini는 Firebase AI Logic으로 부릅니다. API 키를 앱에 넣지 않습니다.
- 보내는 것은 기간별 숫자뿐이고, 경로와 이름은 보내지 않습니다.

## 13. 3D 캐릭터 만든 방법

1. **모델**: 원본(372MB)의 텍스처를 줄이고, 메시를 생김새가 바뀌지 않는 선까지 줄였습니다. (gltf-transform: weld, simplify, quantize)
2. **리깅**: Blender를 스크립트로 돌려 Mixamo 몸의 가중치를 모든 옷·머리 파츠로 옮겼습니다. 먼 뼈의 가중치를 걸러내고, 장갑과 바지가 붙은 면을 잘라 찢어짐을 막았습니다.
3. **동작**: Mixamo 동작 6개를 한 파일에 구웠습니다.
4. **화면**: 앱 안의 작은 서버(`lib/services/asset_server.dart`, 127.0.0.1)가 파일을 내주고, WebView 안 three.js(`assets/viewer/index.html`)가 그립니다. 인터넷 없이 뜹니다.
5. **그림체**: 작게 그린 뒤 픽셀 그대로 키우는 픽셀 필터. 개는 단계마다 픽셀 크기와 채도가 다릅니다.
6. **그림 파일**: 홈 카드 얼굴(`face_*.png`), 플레이어 카드 전신(`card_*.png`)은 같은 3D를 미리 찍어 둔 그림입니다.

| `test/` | 단위·위젯 테스트 |
| `history/` | 날짜별 작업 이력 |

규칙(`lib/game/`)은 화면과 떼어 놓아서, 화면을 바꿔도 규칙은 그대로 쓰고 테스트할 수 있습니다.

## 15. 데이터 구조 (Firestore)

| 컬렉션 | 내용 |
|---|---|
| `users/{uid}` | 닉네임, 레벨, 경험치, 골드, 옷, 캐릭터(`look`), 간식(`snacks`), 먹인 간식(`petFed`), 개 이름(`dogNames`), 배경(`ownedBackdrops`, `backdrop`) |
| `users/{uid}/runs` | 러닝 기록 (본인만 읽기) |
| `leaderboard/{uid}` | 랭킹·대결·친구 찾기용 공개 정보 (닉네임, 레벨, 거리, 모습, 개 단계, 플레이어 번호) |
| `courses` | 사설 코스와 하트 |
| `friendRequests/{보낸사람_받는사람}` | 친구 신청과 수락 |

규칙은 `firestore.rules`에 있습니다.
